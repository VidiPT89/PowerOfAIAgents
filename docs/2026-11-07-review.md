# Review, 2026-11-07

## Fixed

- Measurement start is synchronous; duplicate taps cannot launch overlapping jobs. Cancellation is checked after every suspended operation, preventing a previous run from publishing results or stopping a newer run.
- New runs clear previous results and failure flags. Backgrounding or closing the main view cancels measurements.
- Both classifiers use the same 12 English terms. Accuracy is sample-specific; embedding timing excludes loading the vocabulary. Network requests measure a website, not a cloud model.
- Partial network runs show their actual sample count and failure. First/follow-up labels do not promise connection reuse; system metrics report whether all follow-up requests reused it. Non-success HTTP responses are rejected.
- Applying model measurements copies latency and accuracy, makes the measured agents local, and removes their simulated queue. Accuracy supports 0–100%. Lab bounds and simulated walking/jitter are disclosed.
- Missing embeddings have an explicit state. Empty benchmarks avoid division by zero.
- Submillisecond cascade ratios preserve the actual denominator.
- Measurement controls stack when narrow. Share images regenerate when returning to their tab; race exports identify themselves as simulations.
- Enabling the launch intro from Settings no longer recreates the main screen immediately when the app originally launched with the intro disabled.
- Portuguese accessibility labels use “nuvem”.
